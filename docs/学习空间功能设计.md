# 「程序空间 · 学习空间」功能设计文档

> 角色设定：擅长游戏化设计与社交创新的产品设计师
> 载体：spring-chat 聊天软件
> 文档版本：2026-08-22 v1

---

## 0. 容器定位：什么是「程序空间」

「程序空间」是聊天软件内一个**可拓展的轻应用容器**，类似微信的「小程序/发现页」但更聚焦「人和人一起做点正事」。它把原本零散的娱乐、功能、学习类玩法聚合成一个个**独立空间**，每个空间都能调用聊天软件的底层能力（好友关系链、IM、群、通知、语音、资料卡）。

**首批空间规划：**
- 🎮 娱乐空间（你画我猜、好友小游戏、语音派对）
- 🛠 功能空间（文件快传、日程共享、待办协作）
- 📚 **学习空间（本文重点）**

「学习空间」的设计总纲：**让学习从"一个人的苦修"变成"一群人的日常"**。

---

## 1. 设计原则落地说明

| 原则 | 在空间里怎么体现 |
|------|------------------|
| 社交驱动 | 每个功能的"开始按钮"都依赖好友关系：组队、匹配、PK、共享、互赞，没有好友就玩不起来 |
| 轻量上手 | 所有核心行为控制在 3 次点击 / 5 秒内：进自习室、开番茄钟、匹配搭子均一键发起 |
| 正向激励 | 成就、装扮、点亮、连击、好友鼓励信——只奖励"坚持"，不奖励"碾压别人" |
| 防焦虑 | 排行榜默认「仅好友可见 + 不显示绝对时长差」；PK 用"进步值"而非"总分"；可随时隐身 |

## 2. 五大方向功能体系

### 方向一 · 共同学习类

#### 2.1.1 同步自习室
- **一句话描述**：和好友开一间虚拟自习室，彼此看得见"正在学什么、学了多久"，像在同一张桌子上。
- **用户痛点**：独自学习易走神、缺陪伴感；视频监督又太重、有社恐压力。
- **核心玩法**：
  1. 在聊天侧栏点「学习空间 → 开自习室」，选学科标签（考研/外语/编程…）。
  2. 系统生成房间，自动邀请 3 位常聊好友（可手动改）。
  3. 进入后每个人显示一个"专注卡片"：头像 + 当前科目 + 实时番茄数（不露脸、不录音）。
  4. 谁走神（切出 App 超 2 分钟）卡片变灰"暂离"，回来自动恢复。
  5. 结束时全员弹"今日共专注 XX 分钟"合影卡片，可一键发朋友圈式动态。
- **创新点**：用"状态可见"替代"摄像头监控"，零隐私负担地制造同侪在场感；离散专注也可累加，不强制同时在线。
- **与聊天软件联动**：房间从聊天侧栏发起；自习中消息自动转「免打扰+稍后回」；结束合影走动态流。

#### 2.1.2 学习搭子匹配
- **一句话描述**：AI 根据你的目标、作息、节奏，从好友的好友里给你匹配"同频搭子"。
- **用户痛点**：想找人一起学，但冒昧私聊陌生人尴尬；好友不一定同目标。
- **核心玩法**：
  1. 填 3 个标签（目标/可学时段/每日时长意愿）。
  2. 系统在「二度好友 + 同校/同城」里按作息重合度打分推荐。
  3. 看到推荐卡（匿名昵称 + 重合度 + 共同好友数），点「递搭子申请」。
  4. 对方通过即建立"搭子关系"，解锁互看专注日历。
  5. 连续 7 天同频打卡，关系升级为"黄金搭子"，解锁专属表情包。
- **创新点**：基于"好友关系链"的弱社交破冰，比公开广场匹配更可信、更低尴尬；用"二度人脉"而非陌生人。
- **与聊天软件联动**：匹配成功后自动建双人「搭子群」（轻量、无多余功能）；申请走好友申请同款通道。

#### 2.1.3 好友学习 PK 擂台
- **一句话描述**：和好友约一场"学习时长擂台"，比谁更坚持，而非谁更卷。
- **用户痛点**：纯排行榜让人焦虑；和陌生人比没动力；和好朋友比才有意思。
- **核心玩法**：
  1. 选 1 位好友发起「7 天擂台」，约定每日最低时长（如 1 小时）。
  2. 双方每日专注时长自动计入，擂台页显示"达标天数"进度条。
  3. 任一方连续 2 天未达标，对方获"领先"徽章。
  4. 7 天结束，达标多者胜，败方发一条"认怂"趣味表情（不公开羞辱）。
  5. 胜方可把战绩设为聊天状态（"本周擂台胜"）。
- **创新点**：比"达标天数"而非"总时长"，弱者也有胜算，杜绝时长军备竞赛；败方互动是趣味而非羞辱。
- **与聊天软件联动**：擂台从好友资料卡「约一局」入口发起；每日达标提醒走系统通知；战绩可作聊天签名。

#### 2.1.4 组队打卡日历
- **一句话描述**：和固定小队每天打卡，漏卡有队友"拍一拍"提醒，全队连续天数越长全员加成越高。
- **用户痛点**：个人打卡易断；断一天就放弃；没人催就懒。
- **核心玩法**：
  1. 建 3–6 人小队，设共同目标（如"每天阅读 30 分"）。
  2. 每日任意成员打卡，日历点亮一格；全队当日全亮触发"满勤特效"。
  3. 晚 10 点未打卡者，队友可发「拍拍」提醒（限 2 次/人）。
  4. 连续 21 天全队满勤，解锁队徽 + 全员专注加成 +10%。
  5. 队伍可设"佛系模式"：允许每月 3 天请假不破纪录。
- **创新点**：把"断卡焦虑"转成"队友温情提醒"，用团队连击代替个人意志力；佛系请假防弃坑。
- **与聊天软件联动**：打卡动作在群内快捷发起；拍拍提醒复用聊天「拍一拍」；满勤特效进群公告。

### 方向二 · 学习计划类

#### 2.2.1 AI 定制计划
- **一句话描述**：说一句目标（"一个月过六级"），AI 拆成每日可执行的微任务。
- **用户痛点**：想学但不会规划；计划太粗执行不了，太细又劝退。
- **核心玩法**：
  1. 输入目标 + 可用时长 + 起始水平（可选测 3 题）。
  2. AI 生成「周视图计划」，每任务标注预计时长与难度。
  3. 一键"接计划"，计划进入个人空间首页。
  4. 每日推送"今日 3 件事"，完成打勾自动累计。
  5. 每周 AI 复盘：按时完成率、卡点章节，动态微调下周。
- **创新点**：计划颗粒度自适应（菜鸟给更细步骤）；用"完成率"而非"计划完美度"评价，接纳偏离。
- **与聊天软件联动**：计划可「分享给搭子」求监督；每日任务卡可一键转发好友当"立 Flag"。

#### 2.2.2 计划共享广场
- **一句话描述**：把你的好计划一键发布，好友可"复用"并看到原作者的微调记录。
- **用户痛点**：网上计划模板千篇一律、不匹配自己；好计划想分享给同学却要截图。
- **核心玩法**：
  1. 个人计划页点「发布到共享」，填适用人群标签。
  2. 好友在空间广场刷到，点「复用」即克隆为己用。
  3. 复用后可就地微调，系统记录"X 人复用并改了第 3 周"。
  4. 原作者收到"N 人正在用你的计划"，获得「影响力值」。
  5. 高复用计划进「精选」，原作者获专属装扮。
- **创新点**：计划像"开源项目"一样可被复用、派生、看见影响力，比静态模板有生命力。
- **与聊天软件联动**：共享计划卡片可直接发聊天；"求计划"可在群内@好友。

#### 2.2.3 计划接力
- **一句话描述**：一个长期目标由几个好友分段"接力"完成，像跑接力赛。
- **用户痛点**：单人长期目标易半途而废；没人陪跑很孤单。
- **核心玩法**：
  1. 发起接力（如"共读 12 本书"），切成若干段分配给队员。
  2. 每人完成自己那段，在接力棒上签名 + 一句心得。
  3. 接力棒在队员间"传递"，进度墙实时可见。
  4. 全部完成生成"接力纪念册"，含每人贡献。
  5. 未完成段可"求救"，队友认领补位。
- **创新点**：把"责任分散"变成"责任共担+仪式感传递"，用纪念册制造完成闭环。
- **与聊天软件联动**：接力提醒走群通知；纪念册可发动态；求救消息直达队友私聊。

#### 2.2.4 deadline 互助提醒
- **一句话描述**：把作业/考试 deadline 挂上，好友可"认领提醒你"并陪你最后冲刺。
- **用户痛点**：deadline 前夕独自焦虑；没人兜底怕忘；群刷屏提醒又烦。
- **核心玩法**：
  1. 添加 deadline（科目/时间/紧急度），选"是否需要陪跑"。
  2. 好友可点「我来提醒你」，到期前代为推送（限好友，不扰路人）。
  3. 临期 24h 开启"冲刺房"，认领者在线陪跑、可互相发加油。
  4. 按时完成可发"搞定"庆祝，提醒者获「靠谱值」。
  5. 逾期则仅自己可见"翻车记录"，不公开社死。
- **创新点**：提醒权交给"被信任的好友"而非系统轰炸；陪跑房把焦虑场景变社交场景。
- **与聊天软件联动**：提醒走系统通知但署名好友；冲刺房复用语音学习房能力。

### 方向三 · 内容协作类

#### 2.3.1 笔记共建
- **一句话描述**：和好友对同一主题共建一份"共享笔记树"，像协作写 Wiki。
- **用户痛点**：各自记笔记重复劳动；好笔记想给好友却只能发文件。
- **核心玩法**：
  1. 建主题笔记（如"计网知识点"），邀请协作好友。
  2. 每人认领章节，编辑实时同步，显示"谁在写哪段"。
  3. 可插入对方笔记的"引用块"，形成知识网络。
  4. 版本可追溯，误删可回滚；争议处加"讨论贴"。
  5. 完成后一键导出/设为「小队共享资料」。
- **创新点**：笔记从私有资产变"关系资产"，引用机制自然生成知识图谱；轻量 Wiki 而非笨重文档。
- **与聊天软件联动**：笔记变更通知进群；引用块可@原作者；成品发聊天当资料。

#### 2.3.2 知识点互问
- **一句话描述**：好友间互相出题考，AI 按薄弱点生成"专属考卷"发给搭子。
- **用户痛点**：刷题孤单；不知道自己哪里弱；给别人讲题才记得牢。
- **核心玩法**：
  1. 选章节，AI 基于你的错题库生成 5 题"测好友卷"。
  2. 发给搭子，对方作答，系统判分并标红薄弱点。
  3. 错题自动回流到出题方"教学任务"，可发 1 分钟语音讲解。
  4. 互问连续 7 天，解锁"师徒"关系，讲解获「传授值」。
  5. 双方都掌握的知识点从"待巩固"移入"已点亮"。
- **创新点**：用"教别人"巩固自己（费曼学习法社交化）；AI 让出题零成本。
- **与聊天软件联动**：考卷以卡片发私聊；语音讲解走语音消息；传授值进成就。

#### 2.3.3 错题本共享
- **一句话描述**：小队共用一本"错题池"，谁踩坑自动同步，避免集体重复犯错。
- **用户痛点**：错题各记各的；同班同学常错同一题却互不知道。
- **核心玩法**：
  1. 加入小队错题池，拍照/输入题目即入库（AI 自动去重+归类）。
  2. 池内按"错误率"排序，高频错题置顶提醒全员。
  3. 可标记"我已会"，会了的越多个人"排雷值"越高。
  4. 考前一键生成"小队高频错题 20 道"冲刺包。
  5. 踩到新坑者自动@提醒上次错过的队友。
- **创新点**：错题从"个人黑历史"变成"团队防线"；用错误率做集体预警。
- **与聊天软件联动**：新错题进群通知；冲刺包发聊天；排雷值进排行。

#### 2.3.4 学习资料交易
- **一句话描述**：好友间用"知识币"流转优质资料，闲置笔记也能变现。
- **用户痛点**：好资料散落各处；买会员贵；二手资料无信任渠道。
- **核心玩法**：
  1. 上传资料（笔记/模板/真题），标"免费/知识币价"。
  2. 好友用日常学习赚的「知识币」兑换，交易走平台托管。
  3. 下载后评"有用"，优质上传者获「贡献值」+ 被推荐。
  4. 争议资料可"举报"，AI 查重防搬运。
  5. 每月「知识币」可 1:1 换聊天空间装扮。
- **创新点**：学习产出可循环流通，用平台币而非现金降低门槛与合规风险；信用由好友评价锚定。
- **与聊天软件联动**：资料卡发聊天；交易通知走系统；知识币与装扮体系打通。

### 方向四 · 激励反馈类

#### 2.4.1 学习成就体系
- **一句话描述**：把坚持变成可收集的光谱成就，像集邮一样点亮人生进度。
- **用户痛点**：打卡没正反馈；坚持很久看不到"我变好了"。
- **核心玩法**：
  1. 系统发"隐藏成就"：连续 7 天 / 累计 100 番茄 / 首次教别人题…
  2. 达成弹「成就卡」，可收藏进个人展馆。
  3. 成就分"个人系"和"社交系"（如"最佳搭子"需好友授予）。
  4. 月度生成「成长月报」：时长、连击、教学次数。
  5. 展馆可设"仅好友可见"，避免公开攀比。
- **创新点**：成就强调"过程与关系"而非"排名"；社交系成就需他人授予，强化连接。
- **与聊天软件联动**：成就卡发动态；"最佳搭子"由好友投票授予；月报可转发。

#### 2.4.2 虚拟空间装扮
- **一句话描述**：用学习赚的「知识币」装饰你的学习空间小屋，好友来访可见。
- **用户痛点**：学习软件冰冷；没"我的地盘"归属感。
- **核心玩法**：
  1. 个人学习空间是一间可装饰小屋（书桌/宠物/背景）。
  2. 用知识币买家具，持续打卡解锁限定皮肤（如"考研战袍"）。
  3. 好友可"串门"留便签、点小爱心。
  4. 装扮进度反映真实学习数据（书架高度=累计时长）。
  5. 每月主题展（如"夏日书房"），装扮可参赛互评。
- **创新点**：数据可视化成"有温度的房间"；串门机制把个人空间变社交节点。
- **与聊天软件联动**：从好友资料卡「去TA的空间」串门；便签走留言；装扮秀发动态。

#### 2.4.3 好友点赞鼓励墙
- **一句话描述**：好友每完成一次专注，你可以"偷偷递一张鼓励纸条"，不张扬但暖。
- **用户痛点**：想夸朋友又怕公开尴尬；公开排行榜压力大。
- **核心玩法**：
  1. 刷到好友"刚专注 50 分钟"动态，点「递纸条」。
  2. 选预设暖语（"稳！"/"陪你"）或手写一句。
  3. 对方仅自己收到，不进公开流。
  4. 累计收 100 张纸条获「被温暖的人」成就。
  5. 可设"今日不想被鼓励"免打扰。
- **创新点**：把"点赞"改成"私密的陪伴感"，用一对一温暖替代公开表演。
- **与聊天软件联动**：纸条走私聊免打扰通道；成就进展馆。

#### 2.4.4 轻量学习排行榜
- **一句话描述**：只和好友比"本周进步"，不晒绝对值，看到谁在悄悄努力。
- **用户痛点**：排行榜让人焦虑、造假、攀比总时长。
- **核心玩法**：
  1. 排行仅含互为好友的人，默认隐藏具体分钟数。
  2. 指标是"较上周进步 %"和"连击天数"，非绝对量。
  3. 可一键「隐身」，隐身期间不计入他人榜。
  4. 每周冠军获"本周之光"限时徽章（仅好友可见）。
  5. 榜单下方永远是"你已超过昨天的自己"正向提示。
- **创新点**：用"进步率"重构排行语义；隐身权 + 自我对比兜底，彻底去焦虑。
- **与聊天软件联动**：榜单嵌聊天侧栏；徽章作签名；进步提示走通知。

### 方向五 · 场景创新类

#### 2.5.1 语音学习房
- **一句话描述**：开一间"只放白噪音+偶尔说话"的语音房，好友进来一起学。
- **用户痛点**：视频房太重；纯文字没氛围；想有人声但不想一直聊。
- **核心玩法**：
  1. 开房选「静音自习 / 轻聊讨论」模式。
  2. 成员进房默认闭麦，仅背景白噪音（雨声/咖啡馆）。
  3. 想讨论点「举手」，房主放行后开麦 3 分钟自动收。
  4. 房内有"提问便签"墙，文字异步交流不打断。
  5. 结束时房自动生成"在场名单 + 总时长"。
- **创新点**：语音房用于"在场"而非"表演"；限时麦防跑题；便签墙保留异步讨论。
- **与聊天软件联动**：房从群快捷发起；在场名单发群；便签转群消息。

#### 2.5.2 沉浸式专注模式
- **一句话描述**：一键进入"学习结界"，聊天全静音、屏幕变护眼、种一棵专注树。
- **用户痛点**：学习时手机诱惑大；想专注又怕漏急事。
- **核心玩法**：
  1. 点「进入专注」，选时长（25/45/90 分）。
  2. 期间聊天消息折叠为"专注后可见"，仅白名单（如家人）可穿透。
  3. 屏幕显示一棵成长树，退出即枯（游戏化惩罚轻量）。
  4. 专注中可听空间白噪音歌单。
  5. 结束树入"森林"，森林规模=累计专注。
- **创新点**：用"树"把抽象专注可视化；白名单穿透解决"怕漏急事"真痛点。
- **与聊天软件联动**：专注状态显示于聊天签名；穿透消息走特别提示音；森林秀发动态。

#### 2.5.3 学习直播（轻直播）
- **一句话描述**：开一个"我在学，你可以来看/陪"的轻直播，无美颜无打赏。
- **用户痛点**：正经直播太表演；想让人"云陪读"却没轻量入口。
- **核心玩法**：
  1. 开播选「沉浸式桌面/仅状态」，不露脸。
  2. 观众进来只看到"正在学 X + 实时番茄"，可发弹幕加油。
  3. 主播可置"今日目标"，完成划掉一条。
  4. 下播自动生成"陪读报告"：观看人数、加油数。
  5. 观众可"一键加入同主题自习室"转化留存。
- **创新点**：直播去表演化、只做"在场陪伴"；弹幕是加油而非互动，降低主播负担。
- **与聊天软件联动**：开播走动态；观众从动态进；报告发聊天。

#### 2.5.4 番茄钟社交化
- **一句话描述**：和好友"同开一个番茄钟"，一起 25 分钟、一起休息，节奏同步。
- **用户痛点**：番茄钟一个人难坚持；休息时易跑偏。
- **核心玩法**：
  1. 在自习室/搭子群点「开番茄」，好友可加入同钟。
  2. 全员计时同步，开始/休息/结束同频震动。
  3. 休息 5 分钟弹出"一起喝口水"轻互动（表情/小游戏）。
  4. 完成一个番茄全员 +1，连做 4 个解锁" deep 状态"。
  5. 钟内有人退出，其余人收到"TA 暂离"，但不中断自己。
- **创新点**：把个人番茄钟变成"群体心跳"，同步感替代自律；休息微互动防拖延。
- **与聊天软件联动**：番茄从群/搭子发起；状态进聊天签名；deep 状态发动态。

## 3. 三大爆点功能（深度交互流程）

> 评选逻辑：① 5 秒可开始（轻量）② 强依赖好友链（社交）③ 天然可传播（爆点）④ 低焦虑（正向）。综合选出：**同步自习室、好友学习 PK 擂台、学习搭子匹配**。

### 爆点一 · 同步自习室

**完整交互流程**

```
[入口] 聊天主界面 → 左侧「学习空间」Tab → 顶部「开自习室」按钮（1 次点击）
   │
   ▼
[建室] 弹窗：选 1 个学科标签（考研/外语/编程/考证/阅读/其他）
           系统预填 3 位"常聊好友"为邀请对象（可删/可加，最多 8 人）
           开关：「允许路人通过共享广场加入」（默认关，防焦虑）
   点「开始」→ 房间创建成功（总耗时 < 5 秒）
   │
   ▼
[在场] 每人一张「专注卡片」：
       头像 + 昵称 + 科目 + 🍅实时番茄数 + 今日累计
       状态：专注中(绿) / 暂离(灰, 切出App>2min) / 休息(蓝)
       无摄像头、无麦克风 → 零隐私压力
   房主可见「在场人数」与「全队今日总专注」
   │
   ▼
[互动] 卡片点开 → 可发「递杯水」表情（不弹窗、仅卡片飘一朵💧）
       可「拍拍」提醒暂离好友（限 1 次/10 分钟，防骚扰）
       底部「讨论便签」墙：文字异步，不打断专注
   │
   ▼
[结束] 任一人点「结束今日自习」或 23:59 自动归档
   → 弹「今日自习合影」：全员头像 + 各自时长 + 一句 slogan
   → 按钮：「发动态」（朋友圈式）/「仅自己留念」/「再开一间」
   发动态后，好友在 feed 看到「和 X 人一起专注了 YY 分钟」+ 合影
```

**为什么爆**：同侪在场感是学习最强外驱力；零隐私（不露脸不录音）让社恐也能用；合影天然适合转发，自带裂变。

---

### 爆点二 · 好友学习 PK 擂台

**完整交互流程**

```
[发起] 好友资料卡 → 「约一局」→ 选「学习擂台」
   设置：周期(7天) + 每日达标线(如 60 分钟) + 赌注(趣味表情/称号, 非金钱)
   点「发送」→ 对方收「擂台邀请」卡片（聊天内，带倒计时 24h 接受）
   │
   ▼
[进行] 双方聊天签名自动挂「⚔️擂台进行中」
   每日：各自专注时长自动同步进擂台页（不用人肉填报）
   擂台页显示两人「达标天数进度条」+ 「当前连击」
   任一方当日未达标 → 对方获「领先」小徽章（仅双方可见）
   每日 21:00 系统通知：「今日你达标 / 对方暂未达标，加油！」
   │
   ▼
[结算] 第 7 天 24:00 自动结算：
   达标天数多者胜
   胜方：聊天签名变「🏆本周擂台胜」+ 获「击败X」趣味成就
   败方：弹「认怂」趣味卡（可选发"下次赢回来"表情，不公开羞辱）
   平局：双方获「旗鼓相当」成就
   │
   ▼
[传播] 战绩可一键发动态：「和@好友 打了场擂台，我赢了/惜败」
   好友可「挑战你」→ 形成擂台链，社交裂变
```

**为什么爆**：和"熟人"比才有持续动力；比"达标天数"而非"总时长"让弱者也有胜算，杜绝卷王碾压；赌注是趣味而非金钱，合规且低门槛；战绩卡天然可转发挑衅好友。

### 爆点三 · 学习搭子匹配

**完整交互流程**

```
[启动] 学习空间首页 → 「找搭子」入口（1 次点击）
   首次填「搭子卡片」：3 个标签
     · 目标（考研/雅思/软考/读书…）
     · 可学时段（早/午/晚/夜猫）
     · 每日意愿（30min/1h/2h+）
   系统提示「已用于匹配，仅向二度好友展示」→ 消除隐私顾虑
   │
   ▼
[匹配] 算法在「好友的好友 + 同校/同城」中按：
       目标重合 > 时段重合 > 节奏接近 > 共同好友数  打分排序
   返回 3 张推荐卡（匿名昵称 + 重合度% + 共同好友数 + 一句自评）
   可「换一批」刷新
   │
   ▼
[破冰] 对某人点「递搭子申请」→ 对方收「有人想和你做搭子」卡片
   卡片含：你的匿名画像 + 共同好友背书（"你们都认识 XX"）
   对方「通过」→ 建立「搭子关系」，自动建双人轻量群
   │
   ▼
[共生] 搭子群内：
     · 互看「专注日历」（哪天学了、学了多久，不露内容）
     · 一键「开同步自习室」/「开番茄钟」快捷按钮
     · 每日互发「今日 flag」（一句话目标）
   连续 7 天同频 → 升级「黄金搭子」→ 解锁专属表情包 + 双人成就
   任一方 14 天无互动 → 关系自动休眠（不尴尬、可随时重启）
   │
   ▼
[裂变] 黄金搭子可「再找第 3 人」扩成 3 人小队
   推荐时优先展示「你好友的搭子」，关系链指数扩散
```

**为什么爆**：用"二度人脉 + 共同好友背书"解决陌生人匹配的信任与尴尬；把"找人一起学"这件高门槛社交变成 3 次点击；关系休眠机制免去"删好友"的社交压力，留存更自然。

## 4. 落地优先级建议（给研发）

| 阶段 | 功能 | 理由 |
|------|------|------|
| MVP（2 周） | 同步自习室 + 番茄钟社交化 + 沉浸式专注 | 零新增数据表（复用好友/群/IM/通知），5 秒可玩，最快验证社交学习假设 |
| MVP+（3 周） | 学习搭子匹配 + 好友 PK 擂台 + 成就体系 | 引入轻量关系链拓展，验证匹配与竞争留存 |
| 增长期 | 计划共享/接力 + 笔记共建 + 错题池 + 装扮 | 内容与资产沉淀，提升切换成本 |
| 成熟期 | 资料交易 + 学习直播 + 轻排行 | 生态与商业化，需合规兜底 |

**技术复用提示**：所有功能均走现有 `X-Token` 鉴权、`/topic/user/{uid}` 单播、好友关系 `friendship` 表、通知 `notice` 体系与动态 `moment` 流，无需新增大通道；唯一新增基础设施是「学习空间」独立模块表（房间/计划/成就/装扮），建议放 `resources/update-sql/` 增量迁移。
